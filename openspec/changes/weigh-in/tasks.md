# Tasks

Every task's verify command is `swift test --package-path Packages` (and, where noted, `xcodebuild ... build`), folded into `./verify` before each child closes. Each task names its bead, its requirement heading and spec file, and maps each scenario the requirement lists to a test here or to a `deferred: <bead id>` pointer.
